# Arsnovaa Studio — AI Engineering & Growth Website

An original responsive multi-page website for Arsnovaa Studio, based in Indore, Madhya Pradesh, India.

## Website structure

- Home: strategic hero, services, AI workflow illustration, industries, working process
- Services: 6 dedicated detail pages covering AI automation, AI development, websites & apps, performance marketing, SEO/local growth, and brand/creative
- Industry solutions: healthcare, e-commerce & D2C, startups & SaaS, and professional services
- About, approach, contact, privacy
- Insights: 3 original educational articles about AI workflow automation, local SEO in Indore and production-minded AI product engineering

There are **21 HTML pages** plus sitemap, robots, favicon, accessible navigation JS and responsive stylesheet.

## Run locally

This is an intentionally static, dependency-free site.

```bash
python3 -m http.server 8080
```

Visit http://localhost:8080. The intended production host should support folder/index.html canonical URLs. Recommended: deploy repository through Cloudflare Pages or Netlify as a static site, with publish directory set to repository root and **no build command**.

## Launch checklist

1. **Domain is not verified.** All canonical tags and sitemap URLs currently assume `https://arsnovaa.studio`. If the real company domain is different, replace this value throughout.
2. **Email is not verified.** `hello@arsnovaa.studio` is a placeholder mailto address and must be configured or replaced before launch.
3. Check the privacy page against actual email/analytics providers, business data practices and legal requirements.
4. Connect and verify the domain, check HTTPS, and submit `/sitemap.xml` in Google Search Console.
5. Validate business name, address, Google Business Profile, phone number and office eligibility before publishing local business citations. Only Indore city is represented, not an invented street address.
6. Add actual named team profiles, verifiable projects, screenshots, testimonials, published apps, engineering write-ups and results to make the website stronger for startup programs. This first version **does not claim** AWS partner status, Anthropic/Claude membership, awards, case studies, funding or certifications.
7. Replace the static mailto with a working enquiry form when a suitable backend or service is ready.
8. Check visual and functional behaviour on all target devices after deployment; rankings are not guaranteed.
